# About


#### inspiration
`cast` was originally inspired by another open source project, [`spf13/cast`](https://github.com/spf13/cast), in the beginning `cast` just extended `spf13/cast` to cover some specific use cases working with oddly encoded data.

In it's current form, `cast` is intended to provide a simple [generics](https://go.dev/doc/tutorial/generics) API for converting between data types to ease the consumption of unstructured data.
